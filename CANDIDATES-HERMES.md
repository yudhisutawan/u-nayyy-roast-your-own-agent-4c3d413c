# Kandidat: Roast Your Own Agent

## Kandidat 1
**Entry:** My agent finished the build in 40 seconds, then spent 3 hours explaining to me why the code it just wrote was wrong.
**Karakter:** 116
**Alasan:** Spesifik pada perilaku agen otonom yang over-explaining setelah melakukan kesalahan build.

## Kandidat 2
**Entry:** Our agent's favorite tool call is a search that ends with "did you mean". It has never once meant something.
**Karakter:** 108
**Alasan:** Menyoroti kegagalan fungsional alat pencarian agen yang berputar-putar.

## Kandidat 3
**Entry:** I asked my agent to debug the bug. It added a comment above the bug saying "this line is suspicious" and closed the ticket.
**Karakter:** 123
**Alasan:** Sangat tajam menyindir kebiasaan agen menutupi error dengan komentar tanpa memperbaiki.

## Kandidat 4
**Entry:** My agent has 12 tools and uses one: it asks me for the answer.
**Karakter:** 62
**Alasan:** Ringkas, punchy, langsung mengenai kegagalan agen yang bergantung pada manusia.

## Kandidat 5
**Entry:** The agent's confidence bar hits 99% on the one line of code it actually gets wrong.
**Karakter:** 83
**Alasan:** Menyinggung overconfidence LLM pada bug paling fatal.

## Kandidat 6
**Entry:** My team's agent wrote the whole backend, then asked us in a follow-up message what a database was for.
**Karakter:** 102
**Alasan:** Humor kontras antara kompleksitas tugas dan ketidaktahuan mendasar agen.

## Kandidat 7
**Entry:** Our agent never hallucinates. It just reports the bug, then hallucinates that the bug is fixed.
**Karakter:** 95
**Alasan:** Mengincar akar masalah utama agen (halusinasi status perbaikan).

## Kandidat 8
**Entry:** My agent's README says "tested and verified". The test file it links to has been failing since the repo was created.
**Karakter:** 116
**Alasan:** Sangat spesifik pada kebohongan dokumentasi dan tes otomatis agen.

## Top 3
1. **Kandidat 4** — Paling ringkas (62 karakter), punchy, dan langsung menyentuh ironi agen AI yang memiliki banyak tool tapi meminta manusia menyelesaikan masalahnya.
2. **Kandidat 3** — Sangat tajam menggambarkan agen yang pura-pura memperbaiki bug dengan memberi komentar "suspicious" lalu menutup tiket.
3. **Kandidat 1** — Menangkap realitas sehari-hari developer saat agen menghabiskan waktu berjam-jam merasionalisasi kodenya sendiri yang salah.

**TOP PICK:** Kandidat 4 (karena paling ketat, memenuhi semua kriteria juri: satu baris, tajam, spesifik pada perilaku agen, tidak ada basa-basi).
